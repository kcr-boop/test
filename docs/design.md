# 视觉规范：墨与朱

设计稿（Claude Design 画布，含 7 个小程序页面与规范板）：https://claude.ai/artifact/ERoH7ijedVF7uoRk18Z7mh

宣纸为底，浓墨为字，朱砂只用在“此刻”：正在弹的音、要按的键、要付的钱。石青标记声音与工具状态。

## 色彩

| 令牌 | 名称 | 值 | 用途 |
| --- | --- | --- | --- |
| `--paper` | 宣纸 | `#F5F1E8` | 页面底色 |
| `--paper-white` | 纸白 | `#FFFDF8` | 卡片、播放器 |
| `--ink` | 浓墨 | `#1E1C19` | 正文、主按钮、选中描边 |
| `--ink-soft` | 淡墨 | `#5B554C` | 次要文字 |
| `--ink-muted` | — | `#6B6458` | 辅助文字、未选中标签 |
| `--cinnabar` | 朱砂 | `#A8321F` | 当前音高亮、开始编配、支付 |
| `--cinnabar-soft` | 朱砂浅 | `#F6E3DE` | 识别异常提示 |
| `--azurite` | 石青 | `#2D5A5E` | 音频轨、处理状态、推荐标签 |
| `--line` | 界线 | `#E2DACB` | 卡片描边 |

## 字体

- 思源宋体（Noto Serif SC）700：标题、曲名、简谱数字、白话指法
- 思源黑体（Noto Sans SC）400 / 500：正文与控件
- 减字谱：正式版用 guqin-jianzipu-font 合体字；设计稿中以部件叠排示意

## 页面

| 页面 | 关键点 |
| --- | --- |
| 首页 · 导入 | 拍照为主按钮；聊天记录 / 相册、文件为次按钮；继续打谱列表 |
| 识谱校对 | 三步进度；简谱 / 五线谱切换；异常小节虚线朱框；点音修改音高与时值 |
| 编配设置 | 正调七弦示意；入门 / 进阶、流行 / 古韵卡片；自动选调开关 |
| 三谱对照 | 五线 · 简谱 · 减字逐音对齐，小节线贯穿三行；当前音朱砂高亮；白话指法卡；0.5 / 0.75 / 1× 与单句循环 |
| 一句话编辑 | 三条音轨；指令气泡 + 拆解步骤；示例指令；语音 / 文字输入 |
| 预览与解锁 | 前 8 小节可看，其后渐隐；三档单选；支付按钮随档位变价 |
| 我的琴谱 | 搜索、筛选；打开 / 重新编配；长图 / PDF / MusicXML / MP3 导出 |

## 规则

- 触控高度 ≥ 44px（88rpx）；圆角 6 / 10 / 12 / 16
- 卡片 1px `--line` 描边，选中改 1.5px 浓墨
- 不用渐变底、emoji；图标为 1.8px 线性
